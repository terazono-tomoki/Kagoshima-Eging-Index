# Kagoshima Eging Index（鹿児島エギング指数）

鹿児島県のエギング（イカ釣り）ポイント向けに、**「今日・今週は釣りやすいか」** を天候データから可視化する Web アプリケーションです。

地図上でポイントごとのコンディションを確認し、釣果を写真付きで記録できる、個人開発の実用ツールです。

---

## このプロジェクトでやっていること

| 領域 | 内容 |
|------|------|
| **データ取得** | 無料の気象・海洋予報 API（Open-Meteo）から、風・波・水温・気圧・潮の目安を取得 |
| **判定ロジック** | エギング向けの独自スコアリングで S〜D のランクと週間予測を表示 |
| **可視化** | 地図（Folium）とダッシュボード形式の UI（Streamlit） |
| **データ保存** | 釣果ログを PostgreSQL に保存。写真はクラウドストレージ（S3 互換）にも対応 |
| **運用** | Streamlit Cloud 上で公開運用を想定した構成 |

---

## 主な機能

### 1. エギング指数・予測

- 鹿児島県内の釣りポイント（例：東風泊、佐多岬）を地図上に表示
- 選択したポイントの **本日の総合ランク・スコア** と、潮・風・波・水温の内訳を表示
- **1週間先まで** のコンディション予測を一覧表示

### 2. 釣果ログ

- 釣果（日時・ポイント・サイズ・杯数・メモ）を登録
- 登録時の気象データを自動で紐づけ
- イカの写真をアップロードして一覧・編集・削除
- 過去の釣果と「今日のコンディションが似ているか」を参考表示（ログが一定件数ある場合）

### 3. アクセス制御

- 釣果ログの閲覧・編集はパスワードで保護（簡易的な運用向け）

---

## システム構成（概要）

```
[ブラウザ]
    ↓
[Streamlit アプリ (app.py)]
    ├→ Open-Meteo API … 天候・海況の取得
    ├→ PostgreSQL … 釣果ログの保存
    └→ オブジェクトストレージ … 釣果写真（任意）
```

アプリ本体は `app.py`（画面・保存・認証）、予報取得とスコア計算は `eging_forecast.py` に分離しています。

---

## このプロジェクトで見せられるスキル

採用・ポートフォリオの観点では、次のような実装経験を示せます。

- **要件からプロダクトを形にする力** … 趣味・実用ニーズ（エギング）を Web アプリとして設計・実装
- **外部 API の利用** … 第三者の気象データを取得し、アプリ用の指標に変換
- **ドメイン固有ロジックの設計** … 汎用天気予報を、釣り向けの評価指標へ落とし込む
- **データの永続化** … RDB への CRUD、画像ファイルのクラウド保存
- **Web アプリの UI/UX** … タブ構成、地図、フォーム、一覧表示などの画面設計
- **クラウド運用の意識** … Secrets 管理、デプロイ環境を前提とした設定分離

## ローカルでの起動（概要）

1. 依存パッケージをインストール

```bash
pip install -r requirements.txt
```

2. `.streamlit/secrets.toml` に接続情報を設定（`secrets.example.toml` を参考）

3. アプリを起動

```bash
streamlit run app.py
```

※ 釣果ログ機能を使うには PostgreSQL の接続設定が必要です。詳細は `secrets.example.toml` を参照してください。

---

## 注意事項

- 表示されるランク・スコアは **参考情報** です。実際の海況・潮流・地形は反映していません。
- 出釣前は必ず最新の天候・海況をご自身で確認してください。
- 釣果ログのパスワード保護は簡易的なものです。公開運用時はアクセス制限の追加を検討してください。
